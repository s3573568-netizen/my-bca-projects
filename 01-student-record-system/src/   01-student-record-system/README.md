# Student Record Management System

Ek simple C program jo student records ko manage karta hai — 
add, view, search, update aur delete karne ke liye. Data ek file 
mein save hota hai taaki program band karne ke baad bhi records 
safe rahein.

## Features (planned)
- Add new student record
- View all records
- Search record by roll number
- Update existing record
- Delete record

## How to run
1. Compile: `gcc src/student.c -o student`
2. Run: `./student`
